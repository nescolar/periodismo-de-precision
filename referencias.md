## Glosario

| Término | Definición |
|:--|:--|
| **Censo** | Observación de todos los elementos de la población. |
| **Correlación (r)** | Medida de la fuerza y dirección de la relación lineal entre dos variables cuantitativas; va de −1 a 1. |
| **Cuartiles (Q1, Q3)** | Valores por debajo de los cuales está el 25 % y el 75 % de los datos ordenados. |
| **Desviación estándar** | Distancia típica de los valores respecto a la media. |
| **Hipótesis nula (H0)** | Supuesto de que no hay diferencia o efecto, que se contrasta con los datos. |
| **Intervalo de confianza** | Rango de valores plausibles para un dato de la población, calculado como estimación ± margen de error. |
| **Margen de error** | Variación esperable de una estimación debida al azar del muestreo. |
| **Media** | Suma de los valores dividida por el número de valores. |
| **Mediana** | Valor central de los datos ordenados. |
| **Moda** | Valor o categoría más frecuente. |
| **Muestra** | Parte de la población que efectivamente se observa. |
| **p-valor** | Probabilidad de observar una diferencia al menos tan grande como la encontrada si la hipótesis nula fuera cierta. |
| **Población** | Conjunto completo de elementos sobre el que se quiere concluir. |
| **Puntos porcentuales** | Diferencia entre dos porcentajes. |
| **Rango intercuartílico (RIC)** | Q3 − Q1; amplitud del 50 % central de los datos. |
| **Sesgo** | Error sistemático que hace que la muestra o la medición no reflejen la población. |
| **Tamaño del efecto** | Magnitud de una diferencia o relación, expresada en unidades comprensibles. |
| **Tasa** | Cantidad dividida por un denominador que permite comparar (por ejemplo, por cada 100.000 habitantes). |
| **Unidad de observación** | Aquello que describe cada fila de una base de datos. |
| **Valor atípico** | Valor muy alejado del resto; por convención, a más de 1,5 RIC de Q1 o Q3. |
